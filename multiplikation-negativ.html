Multiplikation negativer Zahlen

● lokal · ohne Speicherung

Fortsetzung eines Multiplikationsmusters über die Null

(−1) · (−2) = ?

Warum sollte das Ergebnis positiv werden?

Der erste Faktor wird jedes Mal um 1 kleiner.

3 · (−2)= −6

2 · (−2)= −4

1 · (−2)= −2

0 · (−2)= 0

+2 +2 +2

Das Ergebnis wird jedes Mal um 2 größer.

0 → 2 +2 (−1) · (−2) = 2

Das Muster geht über die Null hinweg weiter.

(−2) · (−2) = 4 (−3) · (−2) = 6

Damit das Muster erhalten bleibt, werden die Produkte positiv.

negativ · negativ → positiv

Warum sollte das Ergebnis positiv werden?

Das Muster läuft über die Null weiter. Deshalb wird negativ · negativ positiv.
