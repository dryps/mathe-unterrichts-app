# K4.3 – Ungleichungen mit negativen Zahlen

## Verbindlicher Modulvertrag

- Frage: **Warum dreht sich bei einer negativen Zahl das Ungleichheitszeichen um?**
- Untertitel: **Ungleichungen mit negativen Zahlen**
- Ausgang: `2 < 5`
- Operation: Multiplikation beider Zahlen mit `−1`
- Ergebnis: `−2 > −5`
- Bühne: Eine einzige Zahlengerade wird an der Null gespiegelt.
- Aha: **Negative Skalierung kehrt die Ordnung um.**

## Zustandsfolge

1. Irritation: Nur Ausgangsvergleich und offene Frage.
2. Ordnung: Die Lage `2` links von `5` wird auf der Zahlengeraden sichtbar.
3. Spiegelung: Beide Punkte bewegen sich gleichzeitig und gesperrt durch die Null.
4. Ergebnis: `−5` liegt links von `−2`; daraus folgt sichtbar `−2 > −5`.
5. Erkundung: Ein Regler variiert das Paar `(a, a + 3)` innerhalb sicherer Ganzzahlgrenzen.
6. Schluss: Nach der ersten echten Änderung erscheint der exakte Aha-Satz.
