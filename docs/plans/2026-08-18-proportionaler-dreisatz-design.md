# K6.3 – Proportionaler Dreisatz

## Ziel

Aus `3 Stück → 7,50 €` wird durch dieselbe Division auf beiden Größen `1 Stück → 2,50 €`. Von dieser gemeinsamen Einheit führt dieselbe Multiplikation auf beiden Größen zu `8 Stück → 20 €`.

## Lernweg

1. Offene Zielzeile `8 Stück → ?`.
2. `÷ 3` erscheint synchron an Menge und Preis.
3. Die Referenz `1 Stück → 2,50 €` wird sichtbar.
4. `× 8` erscheint synchron an beiden Größen.
5. Das Ergebnis `8 Stück → 20 €` wird sichtbar.
6. Ein Zielregler erkundet weitere Stückzahlen aus derselben Einheitsreferenz; erst jetzt erscheint der exakte Aha-Satz.

Alle späteren Schritte bleiben bis zu ihrem Gate echt verborgen. Animation, Reset und Reduced Motion folgen dem bestehenden deterministischen Modulvertrag. Es wird kein separates Zweisatz-Aha-Modul angelegt.
