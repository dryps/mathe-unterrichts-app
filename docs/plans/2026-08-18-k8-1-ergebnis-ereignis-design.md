# K8.1 – Ergebnis und Ereignis

## Ziel

Das erste Modul des Zufallslabors trennt einen einzelnen möglichen Ausgang von einer Ereignismenge. Die verbindliche Irritation lautet: „Warum ist 4 ein Ergebnis, aber ‚gerade Zahl‘ ein Ereignis?“

## Lernweg

1. Ein Würfel zeigt ausschließlich die 4; noch keine Definition oder Ergebnismenge ist sichtbar.
2. Die 4 wird als einzelnes Ergebnis benannt.
3. Der vollständige Ergebnisraum `{1, 2, 3, 4, 5, 6}` wird sichtbar, ohne ein Ereignis vorwegzunehmen.
4. Das Ereignis „gerade Zahl“ markiert genau `{2, 4, 6}`.
5. In einer kontrollierten Erkundung wechseln Lernende zwischen drei Ereignissen. Damit wird sichtbar, dass ein Ereignis mehrere Ergebnisse, aber auch nur ein Ergebnis enthalten kann.

## Zustands- und Reveal-Vertrag

`irritation → result → room → event → explore`

Jeder Wechsel ist während der kurzen Reveal-Animation gesperrt. `Reset` invalidiert alte Frames und Timer. Bei reduzierter Bewegung endet der Wechsel unmittelbar im mathematisch identischen stabilen Zustand. Inhaltlich spätere Ebenen bleiben bis zu ihrem Gate mit `hidden` aus Darstellung und Accessibility Tree entfernt.

## Mathematik und Zugänglichkeit

- Ergebnisraum des fairen sechsseitigen Würfels: `{1, 2, 3, 4, 5, 6}`.
- Einzelnes Ergebnis: `4`.
- Ereignis „gerade Zahl“: `{2, 4, 6}`.
- Erkundung: „gerade Zahl“, „größer als 4“, „die Zahl 1“.
- Karten, sichtbare Mengenschreibweise, Live-Text und zugänglicher Gruppenname stammen aus demselben reinen Modell.
- Vor dem Ereignis-Gate nennen zugängliche Namen weder „gerade Zahl“ noch `{2, 4, 6}`.

## Abschluss

Verbindlicher Aha-Satz: „Ereignis = Menge aus Ergebnissen.“ Ergänzend bleibt die präzisere kanonische Erklärung sichtbar: „Ein Ergebnis ist ein einzelner möglicher Ausgang. Ein Ereignis ist eine Menge aus einem oder mehreren Ergebnissen.“
