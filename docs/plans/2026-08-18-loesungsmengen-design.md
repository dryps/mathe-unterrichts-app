# K4.4 – Lösungsmengen

## Ziel

Das Modul beantwortet ausschließlich die Frage: „Warum beschreibt eine Ungleichung einen ganzen Bereich statt nur einen Wert?“

## Dramaturgie

1. `2x < 6` irritiert als offene Frage nach möglichen Werten.
2. Ein veränderbarer Testwert macht Einsetzen sowie wahr/falsch sichtbar.
3. Division beider Seiten durch 2 zeigt die Grenze `x < 3`; der Bereich bleibt noch verborgen.
4. Die Zahlengerade markiert kontrolliert alle Zahlen links vom offenen Rand 3.
5. Weitere Testwerte werden räumlich mit der Lösungsmenge gekoppelt.
6. Erst danach erscheint: „Ungleichungen beschreiben häufig Mengen von Lösungen.“

## Produktgrenzen

- statisch, ohne externe Laufzeitdienste
- keine Speicherung und keine personenbezogenen Daten
- Reduced Motion zeigt denselben stabilen Endzustand ohne Bewegung
- Reset entwertet verspätete Animationsrückrufe
- streng kleiner: 3 gehört nicht zur Lösungsmenge
